01

Situation

A smart lock that thinks

My Control Systems final project. Smart locks exist and AI exists — but I hadn't seen the two working together, so I decided to build it: a lock that doesn't just check a PIN, but watches for threats, reasons about them with a local AI model, and physically responds.

02

Task

Solo build — every layer mine

I built the whole system alone: the Arduino firmware, the Python backend, the AI integration, and the web dashboard. That meant owning every interface between layers — serial protocol, API endpoints, and the safety logic that decides when the lock acts.

03

Action

Three layers and a guardrail

The Arduino handles the physical world: keypad entry, brute-force detection at the edge, and the lock mechanism. It streams security logs over USB serial to a Python/Flask backend, where a background listener reacts instantly — OpenCV snaps a webcam photo as evidence, and the log goes to DeepSeek (running locally in LM Studio) for threat analysis. But the AI never acts alone: a two-way guardrail only triggers a lockdown when hardware and AI agree — if the AI misses a real threat, Python overrides it; if the AI hallucinates one, Python blocks it. A live dashboard (HTML/JS) shows lock status, AI summaries, and intruder photos, with a manual override.

System architecture

Arduino + Keypad → Serial log → Flask backend → DeepSeek · LM Studio → Python guardrail → Lock / Lockdown 
# 2-way verification: hardware AND AI must agree.
# Prevents false lockdowns (AI hallucination) AND missed
# real threats (AI failure) — the single most important
# architectural decision in the system.
if hardware_demands_lockdown and ai_wants_lockdown:
    ai_action = "LOCKDOWN"   # both agree
elif hardware_demands_lockdown and not ai_wants_lockdown:
    ai_action = "LOCKDOWN"   # Python overrides the AI
elif not hardware_demands_lockdown and ai_wants_lockdown:
    ai_action = "NONE"       # Python blocks the hallucination
04

Result

Working end-to-end, safely

The full loop runs: a brute-force attempt at the keypad ends with a physical lockdown, photo evidence, and an AI-written threat summary on the dashboard — all on a 1.5B-parameter model running locally, no cloud. The model does hallucinate sometimes; the system stays safe anyway, because the guardrail was designed assuming it would. Engineering for an unreliable component is the whole lesson.
